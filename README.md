# なでしこ簡単ランチャー (Nadeshiko Easy Launcher) v1

「なでしこ日本語プログラム v1」で開発された、シンプルかつ強力なタスクトレイ常駐型ランチャーです。
日常的なWeb検索から、定型的な編集作業までを、最小限の操作で自動化します。

> [!IMPORTANT]
> 本プログラムの動作には、[なでしこ日本語プログラム v1](https://nadesi.com/v1/) の実行環境が必要です。

---

## 🌟 主な特徴
- **超軽量・常駐型:** 起動後はタスクトレイに静かに常駐し、PCのメモリを圧迫しません。
- **スマートUI:** アイコンクリックで瞬時にメニューを表示。操作完了後は自動でトレイに戻ります。
- **安心・安全:** 外部との不要な通信は一切行わず、個人情報の収集もありません。

## 🛠 搭載機能（できること全一覧）

### 1. Webサイト・AIツールへの即時アクセス
ボタン一つで、ブラウザを起動し以下のページを直接開きます。
- **楽天AI:** AIチャットを素早く呼び出します。
- **Google翻訳:** 翻訳画面へダイレクトにジャンプします。
- **YouTube:** 動画視聴をすぐに開始できます。
- **なでしこ公式サイト:** ドキュメントの確認や最新情報のチェックに。

### 2. クリップボード・テキスト操作の自動化
煩わしいキー操作をプログラムが代行します。
- **全選択コピー:** アクティブなウィンドウ内のすべてのテキストを選択し、コピーします。
- **貼り付け実行 (Paste & Enter):** クリップボードの内容を貼り付けた後、自動でEnterキーを送信。検索バーなどで非常に便利です。

### 3. ホットキー（ショートカット）機能
マウスを持たず、キーボードだけで操作を完結できます。
- `Ctrl` + `Alt` + `R` : **楽天AI** を開く
- `Ctrl` + `Alt` + `G` : **Google翻訳** を開く

---

## 📥 セットアップと使い方
1. **実行:** なでしこ v1 環境で本プログラムを起動します。
2. **常駐:** 起動すると画面右下のタスクトレイに「な」のアイコン（またはデフォルトアイコン）が表示されます。
3. **操作:** - アイコンをクリックするとメインメニューが表示されます。
   - 任意の機能を選択すると実行され、自動的に最小化されます。
4. **終了:** メニュー内の「終了」を選択すると、完全にプログラムを閉じます。
