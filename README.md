# なでしこ簡単ランチャー (Nadeshiko Easy Launcher) v1

「日本語プログラミング言語 なでしこ v1」で開発された、シンプルかつ強力なタスクトレイ常駐型ランチャーです。
日常的なWeb検索から、定型的な編集作業までを、最小限の操作で自動化します。

> [!IMPORTANT]
> 本プログラムの動作には、[日本語プログラミング言語 なでしこ v1](https://nadesi.com/top/index.php?cmd=read&page=%E3%83%80%E3%82%A6%E3%83%B3%E3%83%AD%E3%83%BC%E3%83%89) の実行環境（Windows用）が必要です。

---

## 🌟 主な特徴
- **超軽量・常駐型:** 起動後はタスクトレイに静かに常駐し、PCのメモリを圧迫しません。
- **スマートUI:** アイコンクリックで瞬時にメニューを表示。操作完了後は自動でトレイに戻ります。
- **安心・安全:** 外部との不要な通信は一切行わず、個人情報の収集もありません。

## 🛠 搭載機能（できること全一覧）

### 1. Webサイト・AIツールへの即時アクセス
ボタン一つで、ブラウザを起動し以下のページを直接開きます。
- **楽天AI:** AIチャットを素早く呼び出します。
- **Google翻訳:** 翻訳画面へダイレクトにジャンプします。
- **YouTube:** 動画視聴をすぐに開始できます。
- **なでしこ公式:** [なでしこ 1系 ユーザーマニュアル](https://nadesi.com/doc/index.php?%E3%83%A6%E3%83%BC%E3%82%B6%E3%83%BC%E3%83%9E%E3%83%8B%E3%83%A5%E3%82%A2%E3%83%AB)の確認などに。

### 2. クリップボード・テキスト操作の自動化
煩わしいキー操作をプログラムが代行します。
- **全選択コピー:** アクティブなウィンドウ内のすべてのテキストを選択し、コピーします。
- **貼り付け実行 (Paste & Enter):** クリップボードの内容を貼り付けた後、自動でEnterキーを送信。検索バーなどで非常に便利です。

### 3. ホットキー（ショートカット）機能
マウスを持たず、キーボードだけで操作を完結できます。
- `Ctrl` + `Alt` + `R` : **楽天AI** を開く
- `Ctrl` + `Alt` + `G` : **Google翻訳** を開く

---

## 📥 セットアップと使い方
1. **環境準備:** PCに [なでしこ v1](https://nadesi.com/) がインストールされていることを確認します。
2. **実行:** 本プログラム（.nakoファイル）をなでしこで実行します。
3. **常駐:** 起動すると画面右下のタスクトレイにアイコンが表示されます。
4. **操作:** - アイコンをクリックしてメインメニューを表示します。
   - 任意の機能を選択すると実行され、メニューは自動的に閉じます。
5. **終了:** メニュー内の「終了」を選択すると、プログラムが終了します。
